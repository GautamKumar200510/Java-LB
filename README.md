## 🚀 Getting Started

### Prerequisites

Install the following tools:

- Java Development Kit (JDK)
- Visual Studio Code
- Extension Pack for Java in VS Code
- Git (optional, for cloning and version control)

Verify your Java installation:

```bash
java -version
javac -version
```

### Clone the Repository

```bash
git clone https://github.com/GautamKumar200510/Java-LB.git
```

Navigate to the project directory:

```bash
cd Java-LB
```

Open the project in Visual Studio Code:

```bash
code .
```

## ▶️ How to Run a Java Program

1. Open the `src` folder.
2. Open the Java file you want to execute.
3. Make sure the filename matches the public class name.
4. Compile the program using the Java compiler.
5. Run the compiled class.

Example:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Compile and run from the directory containing `Main.java`:

```bash
javac Main.java
java Main
```

Alternatively, use the **Run Java** option in Visual Studio Code if the Java extensions are installed.

## 📚 Suggested Learning Roadmap

1. Java Basics — syntax, variables, data types, and operators.
2. Control Flow — if-else, switch, and loops.
3. Methods — parameters, arguments, return values, and method overloading.
4. Arrays and Strings — traversal and common operations.
5. OOP — classes, objects, constructors, inheritance, polymorphism, abstraction, and encapsulation.
6. Collections Framework — List, Set, Map, and related data structures.
7. Exception Handling — try, catch, finally, and custom exceptions.
8. DSA Practice — arrays, strings, linked lists, stacks, queues, trees, and algorithms.
